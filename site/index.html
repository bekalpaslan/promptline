The killer move

Copy an error, a stack trace or a diff. Hit the hotkey. Pick Root cause first. Your template pastes with the clipboard contents already inserted where {clipboard} was. One gesture turns raw error text into a well-formed prompt.

A tour of both windows

The popup is where you spend a second at a time; the manager is where your library lives. These are the real windows, with a demo library in them.

1 The popup

Summoned over whatever you're typing in

The hotkey opens the popup at your cursor, in any app. Your pinned prompts sit on top with a key each; below them, your packs and their groups, most used first.

  • Ctrl 1…5 pastes a pinned prompt without looking
  • ↵ pastes into the window you came from; Ctrl ↵ only copies
  • Packs and groups fold, and stay the way you left them
2 Preview

See exactly what will land, clipboard included

→ on a row shows the prompt as it will be pasted: {clipboard} already replaced by what you copied, so you know the error made it in before you press Enter.

  • {date} and {time} fill themselves in as it pastes
  • A clipboard carrying invisible or direction-changing characters is flagged before it's pasted
3 Search

A few letters find it

Titles match as you type, letters in order; tags and the text itself come next. The best match is already selected, and the top five take Ctrl 1…5.

  • #tag, @pack and >group narrow the list
  • Ctrl N turns what you copied into a new prompt
4 Fill-in fields

Blanks it asks for, values it remembers

Write {goal} in a prompt and the popup asks for it before pasting, with the result shown as you type. Write {{service}} and the value saved with the prompt goes in without asking.

  • ↵ pastes, Shift ↵ starts a new line, Esc goes back
5 The manager

Your library, arranged the way you think

One pack per project, a group per practice. A pack or group opens as cards with your clipboard and saved values already in place, so you read prompts the way they'll paste.

  • Arrange packs and groups; the popup follows your order
  • Every pack is a plain JSON file the app keeps current, to commit or to share

6 The editor

Edit with everything in view, saved as you type

The prompt, its pack and group, its tags, and every field and saved value it uses, on one page. There's no Save button: it autosaves, and Quit or a Windows shutdown waits for the last keystroke.

  • Click a chip to insert {clipboard}, a field or a config value
  • Undo covers deletes, merges and regroups

7 Generate

Let an AI draft a pack. You decide what stays.

Name a topic and hand the instruction to any chat, or point a coding agent at your project and let it survey the code and write the pack. Nothing is added until you've reviewed it, prompt by prompt.

  • Prompts you already have come in unticked, marked dupe
  • Hidden characters, the kind a model reads and you can't see, are flagged and unticked
Promptline
8 Settings

Yours to tune

Record any hotkey by pressing it, start with Windows and stay in the tray, and pick light, dark or whatever Windows is using. Your library exports to a file or the clipboard and imports from either.

  • Popup density, the font and the UI scale
  • One folder holds everything; Open folder shows it

What's in the box

Works in every window

Claude Code or Codex in a terminal, ChatGPT or claude.ai in the browser, Cursor, a PR comment box. If it has a text field, the prompt lands in it.

Fill-in fields

Write {goal} in a prompt and the popup asks for it before pasting. {{project}} is remembered once and filled in every time.

Packs you can share

Every pack is a plain JSON file the app keeps current. Commit one to a project, export one for a colleague, or let an agent write one.

Let an AI write your packs

Describe a topic, or point a coding agent at your project, and import the pack it produces, curated prompt by prompt.

Keyboard first

Search, pins, groups, a preview with the real clipboard substituted, undo. Every control reachable without a mouse, labelled for screen readers.

Light, dark or the system's

Both windows follow Windows as it switches, or stay the way you set them, with the density, font and scale you like.

  • No network, no telemetryIt never phones home. The only thing that leaves your machine is what you paste.
  • Plain files you ownPrompts, packs and settings are JSON in one folder. Copy it to back up; copy it back to restore.
  • Open source, MITRust and React on Tauri 2. Read it, build it, change it.

The installers are not code-signed yet, so SmartScreen shows "Windows protected your PC" on first run: choose More info → Run anyway. The default hotkey Ctrl Shift V is paste in Windows Terminal and some browsers; record Ctrl Alt V in Settings if that bites.
