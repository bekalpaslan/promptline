The popup's list row: one prompt, its first line, one tag chip (the rest folded into +N), a fill-in count and the Ctrl+digit slot it answers to. The chips sit at the end of the first-line preview, on its baseline, so the title keeps the row's full width; in `compact` rows, which have no preview, they follow the title.

Use it for any list where Enter acts on the selected item. The keyboard selection is a 1.5px bar in `focus` at the row's left edge, no fill, drawn only once an arrow key has moved the selection (`bar`), and the text stays `ink`; mouse hover uses `hover`, never the bar, so a hover cannot be mistaken for the row Enter will paste. The row starts with its title: there is no icon slot. A pinned row carries no mark here (the popup's Pinned heading says it), and a row that would paste an empty clipboard is said by the clipboard line and the hint bar, not drawn. Rows are flat: no border, no shadow, `radius-2` corners, 8px horizontal and 2px vertical padding, the one tree row both windows draw (`treeRowClass`).

The consumer provides the snippet (`entry.s`), match indices for title highlighting (`entry.indices`, or null), `derived` from `derive(snippet)`, and the handlers (`onPick`, `onMove`, `onLeave`, `onTag`). `compact` drops the first-line preview, `bar` draws the selection bar on the selected row (the popup sets it once an arrow key has moved the selection since the summon), `slot` renders the Ctrl+1 pair on the first slot and the digit alone on the rows under it, `activeTags` fills the pills that are current filter terms.

Do not add a border or background to a resting row, and do not colour the selected row's text with the accent.
