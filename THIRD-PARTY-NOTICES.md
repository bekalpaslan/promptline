## Other bundled dependencies

The JavaScript packages whose code or stylesheets end up in the installed
app, from `package.json`'s `dependencies`, with the licence each declares:

| Package | Licence | What it is |
|---|---|---|
| `@base-ui/react` | MIT | the component primitives shadcn/ui builds on (MUI team) |
| `@tauri-apps/api` | Apache-2.0 OR MIT | the bridge between the windows and the Rust core |
| `class-variance-authority` | Apache-2.0 | component variant helper |
| `clsx` | MIT | class-name helper |
| `react`, `react-dom` | MIT | the UI framework |
| `shadcn` | MIT | the component library's shared stylesheet (`shadcn/tailwind.css`) |
| `sonner` | MIT | toasts |
| `tailwind-merge` | MIT | class-name merging |
| `tailwindcss` | MIT | the styling framework; its generated CSS ships, the tool does not |
| `tw-animate-css` | MIT | animation utilities |

Build-time tools (Vite, TypeScript, ESLint, the Tauri CLI) do not ship.
The Rust side is built on [Tauri](https://tauri.app) (Apache-2.0 OR MIT)
and its plugins; the complete list of crates with their versions is in
`src-tauri/Cargo.lock`, and each crate's licence is in its own package
metadata on crates.io.
