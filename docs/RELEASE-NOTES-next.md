### Privacy

- **A private clipboard stays private in the prompt.** When a prompt takes in something your password manager copied as private, the prompt is now marked private too, so Windows keeps it out of clipboard history (Win+V) and doesn't sync it to your other devices. Ordinary prompts still appear in clipboard history as before. Nothing Promptline sends over the network changes.

### Settings

- **Report a bug from Settings → About.** A **Report a bug** button opens a new issue on GitHub in your browser (you'll need a GitHub account to file it), and the version the form asks for is shown beside it. It is the second link the app can open, after the coffee page.
